Privacy Policy

Last updated: November 17, 2026

Overview

Garmin Workout Analytics is a personal application used by its owner to synchronize and analyze Garmin workout data using Google Drive. It is not offered as a public service.

Information Accessed

The application uses the Google Drive API to access and manage files required for personal Garmin workout synchronization, including CSV files, SQLite databases, and backup files.

How Information Is Used

Google Drive access is used to upload, download, organize, and maintain workout data files. Information is used for personal fitness tracking, analysis, and backup purposes.

Data Storage and Security

Workout data is stored on the owner's computer and in the owner's Google Drive account. Google authentication credentials are maintained locally for authorized access.

Information Sharing

The application does not sell personal information or provide workout data to advertisers. It is intended solely for the owner's use.

Data Retention and Deletion

The owner controls retention and deletion of files stored locally and in Google Drive. Google account access can be revoked through Google Account security settings.

Google API Services

The application's use of information received from Google APIs will adhere to the Google API Services User Data Policy , including applicable Limited Use requirements.
